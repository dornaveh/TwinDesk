Connect your PC and Mac

TwinDesk shares your PC keyboard, mouse and audio output with a Mac. Each monitor needs a video cable from each computer.

  1. Install the Mac companion and grant it Accessibility and audio-capture access when requested.
  2. Select the PC address reachable from the Mac in TwinDesk. Start the connection, copy the pairing code, and paste it on the Mac. Keep the code private.
  3. First test keyboard and mouse with monitor switching off. Use the monitor's own input button to show the Mac.
  4. Refresh monitors and match the PC and Mac inputs to your cables. While disconnected, enable monitor switching, then reconnect and test each direction.
  5. Enable audio on the Mac and select your desired Windows output. The PC must stay awake.

Switching

Ctrl + Alt + F12 switches computers. Ctrl + Alt + F11 returns input to Windows. The Mac menu also offers “Switch back to Windows”.

Keep the Mac silent

The audio tap suppresses local sound while streaming. To keep the Mac mini silent when streaming stops, also mute Mac mini Speakers in macOS Sound settings and turn off the startup sound.

Optional storage

The direct-link helper changes a dedicated Ethernet adapter and shares C: and E: with your Windows account. Preview and review these changes before applying them; see the supplied README.md. SMB uses your Windows password, not a PIN.

If something does not switch

This is an experimental preview. Monitor DDC/CI support varies and can fail while the picture remains fine. Use the monitor's physical input button to recover. A software command succeeding does not prove the monitor changed inputs.

Complete build and usage instructions are in the repository's README and the platform READMEs.
